配置语义、执行方式与结果边界。

完整场景任务

  1. 在“实验配置”中设置物理场景，生成完整物理数据。
  2. 配置请求负载、计算硬件、模型部署、V1 Runtime Comm 与故障策略，保存完整场景。
  3. 进入“在线运行”发布任务。运行期间可暂停、注入故障并继续执行。
  4. 任务结束后在“实验结果”查看完成率、延迟与执行记录。

物理配置草稿不能替代完成的物理数据。数据身份、版本或哈希不匹配时需重新准备。更改业务负载、运行策略和故障输入可以复用同一物理数据。

计算 Cell 任务

  1. 设置卫星数量、每星算力卡、硬件与编队构型，或导入 TLE。
  2. 配置星内网络和星间链路；根据需要展开光学与传输参数。
  3. 选择模型与请求流，配置并行部署、显式 Rank 映射和调度器。
  4. 在“调度运行”发布任务。结果页显示实际运行产物；任务记录保留复用配置的入口。

选择 Ring 时自动连接相邻卫星并闭环，选择 Chain 时依次连接全部卫星。修改静态编队的卫星数量或 ID 会重新生成相邻链路，保留已有对应链路的模式与预算。可以在“通信网络”中继续自定义连接；Rank 放置与并行策略保持显式配置。

三维预览

总览以数据中心图标表示计算 Cell；进入后显示该 Cell 内的卫星。进入配置与“重置视角”会将当前编队中心对准画面中央，地球保留为背景。拖动旋转、滚轮缩放；编辑硬件、卡号及链路参数保持视角。

静态编队的轨道高度按地球半径的真实换算后放大 2 倍，数值增加时离地间隙同步增加。星间距离使用单调、有界的局部放大：模型坐标下的编队半径小于地球半径的 31%，避免公里级距离跨越整个地球；具体显示尺度不用于物理测量。卫星图标另按可辨识程度缩放。TLE 使用后端 ECEF 地心坐标，不作局部归一化。

高度和间距编辑只改变对应几何，不自动转动或缩放镜头。预览链路来自配置与后端计算，链路预算、传播时延和任务运行始终使用真实物理参数。总览动画用于示意。

执行与结果

计算与通信由 version/AsterMind-V1.0 对应源码执行，使用官方 vLLM Scheduler 与 Runtime Comm。网页不以演示数据替代仿真结果；任务失败时显示后端错误。编队布局不会自动生成 Rank 放置，也不会把不可见或无效物理链路当成可用连接。

原生算子耗时、显存容量及能耗以模型、硬件配置和实际输出为准。Cell 的 device-only 任务使用零载荷客户端边界，不计算星地接入时间；需要接入过程时使用完整场景。V1 路径事件表示整条路径共享资源，不能当作旧 FlowSim 逐跳传输日志。

尚不能等价运行的旧功能

SGLang、AF / PD+AF、FlowSim ACK、SimGrid / ns-3 独立执行、MTP、旧 Host / KV offload、CUDA Graph、闭环 admission 及旧双引擎对照当前不受此 V1 适配器支持。旧选项保留供配置辨识，提交时明确拒绝。没有对应指标的报告位置显示不可用。
