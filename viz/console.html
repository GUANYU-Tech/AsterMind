计算卫星编队

沿用 planes、clusters_per_plane、satellites_per_cluster、grid_shape、formation_pitch_m 等参数。编队采用独立平均根数初始化并自由 SGP4 传播；不是保持固定相对位置的控制仿真。

接入、链路预算与太阳避让

实际容量由距离、发射功率、孔径、损耗和接收要求计算；终端速率仅为上限。所有数值均按每方向记录。双向 400/100 Gbps 是参考范围，不用于强行校准。未公开终端参数为工程假设，可在 JSON 中修改。

网络传输模式用于完整系统 Runtime：简单模式预约链路并排队；SimGrid 模式由真实引擎计算并发共享带宽。仅通信拓扑诊断不执行业务传输或带宽共享。

系统运行

默认 Llama 3.3 70B / H200；cell 成员数自动分解为 TP×PP（10 个成员采用 TP=2、PP=5）。模型与硬件的更多参数可以在完整 JSON 中编辑。不满足硬件、模型部署或编队约束会明确报错。
