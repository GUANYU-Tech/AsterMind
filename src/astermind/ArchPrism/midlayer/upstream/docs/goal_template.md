## Complete、Checkpoint 与 Blocked

- Completed：全部 hard acceptance gates 有最终证据证明 Pass；或者用户明确豁免仍为 Fail 的 gate 并要求停止。除此之外不得声称完成。
- Checkpoint：代码提交、测试通过、报告/工具修复、部分指标改善、阶段结论、运行时限耗尽、unsupported 或 WONTFIX 单独出现时都只能是 checkpoint。存在任一 Fail 时必须明确写“Goal 未完成”，并继续下一个可行动的高优先级问题，不能提交一次 checkpoint 后等待用户再次要求继续。
- WONTFIX/unsupported：只能针对具体子问题，必须给出边界明确的证据、已否定候选和无法合法继续的原因；“缺少证据”本身意味着继续分析、做受限验证或换方向，不能批量把主要目标标成 WONTFIX。只有当诊断型 hard gate 事先明确把“证明不支持或无法合法修复”定义为可接受结果，并且所需证据全部满足时，该结论才能使对应 gate Pass。
- Blocked：仅当所有剩余有效路径都需要新增授权或遭遇无法绕开的外部阻塞时使用；必须列出阻塞、已推进的其他路径和解除条件，且状态仍不是 completed。
